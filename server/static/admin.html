服务端不保存明文口令，也不接收明文口令 —— 请填入口令哈希串 （形如 $argon2id$v=19$m=19456,t=2,p=1$…$…）。
最简单的是在服务器上跑 clipsync-server hash（输入不回显）， 具体做法见下面「这串哈希怎么生成？」。
写入后请用真实密码登录一次：能登进去，才说明这串哈希确实对应你手里那个口令。

这串哈希怎么生成？ 
# 推荐：服务端自带命令（输入不回显，参数与服务端校验完全一致）
/opt/clipsync-server/clipsync-server hash

# 或用三方工具生成，只要指定这几个参数即可：
#   算法 argon2id，m=19456 KiB，t=2，p=1，输出 PHC 格式串
#   （形如 $argon2id$v=19$m=19456,t=2,p=1$<盐>$<哈希>）

任何能输出 argon2id PHC 串的工具都可以。口令只在你本机出现一次， 不会经过网络，也不会被写进服务端的任何文件。
盐不用另外记：它就明文写在这串哈希里（`…$<盐>$<哈希>` 这两段）， 登录时服务端从串里读出同一个盐、同样的参数再算一遍比对。所以盐是随机值也不会登不上—— 它的作用只是让同一个口令每次生成的串都不一样（防彩虹表）。
